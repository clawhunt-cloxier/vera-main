# T034 浏览器提交研究计划

Codex 于 2026-11-20T14:07Z 领取，分支为 `agent/codex/T034-confirm-research-protocol`，基线为 `7484e387`。

测试站选择贵州茅台后，普通 JSON 创建计划成功。确认页重新读取计划时，0.4 表示返回固定截止模式及最近可用行情策略。旧客户端据此改用 0.4 提交，服务返回 409 PLAN_VERSION_MISMATCH。

修复在客户端先看快照模式。固定截止计划采用普通 JSON，动态采集计划根据是否携带行情要求沿用 0.4 或 observation.v1。后端已有相同的确认规则。桌面和手机浏览器回归模拟创建和读取时不同的表示，覆盖刷新计划页后提交、三种研究和历史计划。

扩展客户端回归后先观察到协议断言失败，再修改客户端。修复后在 `web` 中运行 `npm run test:api-client`、`npm run test:realtime-ui`、`npm run build`、`npm run lint` 与 `npm run format:check` 均通过。部署后验收从测试站搜索贵州茅台，实际点击“提交任务”并打开对应研报。部署版本与现场结果记录在本次 PR。
