## 交付

工作台可开启私人对话，选择对象、确认计划、查看数据及证据，并依照同一会话续问。短研究支持个股日成交和融资余额，单 Choice 日成交有自己的技能版本。完整研报可在对话与原入口生成，正式报告与 PDF 沿用现有协议。会话上下文、身份绑定及技能登记预留 RAG、偏好、IM 和更多研究技能的接入位置。

## 运行结果

- [对话验收命令](../../TESTING.md#conversation-acceptance) 使用实际 PostgreSQL 与 River。验证两项短研究、重复消息、并发确认、确认后取消、对象选择、账户隔离、图表与冻结记录对齐、基于原版本的追问及 60 日续问。
- 使用模拟记录演练收盘研究授权。验证撤销用途与隔离冻结记录时的读取状态，以及同一证据能从另一份可读的报告打开。删除在途任务时推进版本和 epoch，过期后拦截待交付的正式研报。已交付的正式研报与 PDF 在清理后仍可读，短研究已消耗的当日配额保留。
- 使用合成 Choice 动态库与本地 S3 替身，验证图表和明细均展示 180.00 万元，打开同一条归档证据。按留存规则清理对话专属快照，普通观察简报及其冻结快照仍可读。
- 新增回归在会话删除与清理后交付模拟厂商回复，验证迟到计费仍记录用量、实际费用或未知费用预留，回复正文与错误详情保持为空。回归检查旧 epoch 无法增加调用记录、未知费用可以核销，短研究超过时限不能交付。
- `npm run test:conversation-ui` 的 1440×960 与 390×844 流程在 `0ebdcc3` 通过，使用包含实际 API、队列和存储的本地模拟演示。既有 `npm run test:realtime-ui` 的 20 项检查通过。
- 文档、OpenAPI、契约兼容、生成类型、工具链、前端构建、格式检查及受影响的 Go race 测试通过。复现命令见 [TESTING](../../TESTING.md)。
- `0ebdcc3` 的权限、迁移、费用与契约已通过 [独立工程审查](../reviews/2026-11-25-T044-conversation.md)。最终 CI 状态见 PR。
