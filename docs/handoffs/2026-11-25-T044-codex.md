## 交付

工作台可开启私人对话，选择对象、确认计划、查看数据及证据，并依照同一会话续问。短研究使用日成交和融资余额独立版本。完整研报可在对话与原入口生成，正式报告与 PDF 延用现有协议。会话的上下文装配、身份绑定及技能登记预留后续扩展。

## 运行结果

- 实际 PostgreSQL 与 River 的对话验收通过。覆盖两项短研究、重复消息、并发确认、确认后取消、对象选择、账户隔离、图表与冻结记录对齐、基于原版本的追问及 60 日续问。
- 使用模拟记录演练收盘研究授权。撤销用途或隔离冻结记录后，确认、报告、图表、证据、计算与引用路径按相应状态拒绝。验证删除及过期清理、当日配额保留、正式报告和 PDF。
- `npm run test:conversation-ui` 的 1440×960 与 390×844 流程通过。使用包含实际 API、队列和存储的本地模拟演示。既有 `npm run test:realtime-ui` 的 20 项检查通过。
- 文档、OpenAPI、契约兼容、生成类型、工具链、前端构建、格式检查及受影响的 Go race 测试通过。复现命令见 [TESTING](../../TESTING.md)。
