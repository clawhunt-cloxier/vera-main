范围包括 TuShare 官方 HTTP 接口、原始档案、财报与公告的可追溯映射、证券及行业历史数据、研究入口、冻结快照与报告。复用既有数据集，若需迁移或公共契约，先在这里登记。模拟响应仅供测试，真实账号的权限、时点和交付单独验收。

本任务领取迁移 00020，给自选股加入价与每日快照增加来源，同日指标可按厂商独立保存。历史未归属指标保持空来源。该部分由 Harness 子任务独占。

## 交付与复验

开发已提交到 PR #40，目标分支为 dev。实现与运维说明见 [TuShare 收盘研究](../TUSHARE.md)。以 `3fa88c9` 为接口、归档和服务装配基线，`08acdbb` 接入网页三技能，`40f2c37` 与 `17a66b2` 隔离历史报告、自选指标和命令回放，`63859d1` 支持测试部署后台采集。工作树之外的主检出保留原状。

- 在 Linux 上运行 `make verify`，通过文档、公共契约、Go 竞态测试、前端协议、静态检查和构建。Go 包测试需可启动 PostgreSQL，公告提取需 Poppler 和 util-linux。
- `cd backend && go test -race ./internal/app -run '^TestTuShareThreeReportDelivery$' -count=1 -v` 使用合成 TuShare HTTP 响应、可提取的中文 PDF、PostgreSQL、S3 协议测试存储与模拟模型。首次发布 10,780 条记录，重复同步新增 0。工作台 API 和 worker 生成个股 full（50 条结论、4 张图）、资金 limited（25 条、3 张图）、公司深研 limited（58 条、1 张图）。实际读取证据、计算输入与序列，渲染三份 PDF，共 20 页。撤销模型用途后相关证据、计算和 PDF 均返回 503。
- `cd web && npm run test:realtime-ui` 的 Chromium 用例检查三项快速入口、计划确认、报告、证据和 PDF 链接，网页使用模拟 API。PDF 导出已分别渲染为页面图像检查分页、图表和中文显示。
- 尚需在测试环境注入账号 Token，检查实际订阅、公告原文可访问性、真实模型报告并核对引用。开发机到官方 API 的无凭证 TLS 握手出现 EOF，部署时应先从运行容器执行名录探测。真实 V02 验收仍开放。

再次核对数据版本时发现，先发起的采集可能晚于并行采集发布修订前的行情。`fbcddea` 用厂商级数据库会话锁覆盖取数及发布。PostgreSQL 回归覆盖不同调用交错、单连接池和持锁会话被终止三种情况。`2838eb8` 增加有效空响应的原文和请求归档。

`909195f` 通过真实公开年报抽查修复了一种跨行表格。贵州茅台 2024 年报共 143 页，原件 SHA-256 为 `5299f4940e2ce4e91084b73dc457d558b9d335fa76fbfee6227e4254eb7f4a30`。生产解析函数从第 5 页取得归母扣非净利润 86,240,905,977.42 元，业务和风险原文分别定位到第 7 页和第 22 页。这次抽查验证的是公司披露原件及解析，账号调用 `anns_d` 的验收仍需 Token。[年报原件](https://static.cninfo.com.cn/finalpage/2025-04-03/1222993920.PDF)

随后在开发机向官方 HTTPS 地址提交空 Token 的 `stock_basic` 请求，TLS 校验成功，服务返回鉴权错误 40101。测试站仍需验证真实订阅。复核现有 Choice 部署时发现，沿用 `VERA_REQUIRE_CHOICE_QUOTE=true` 将导致 TuShare 首次同步后仍无法就绪。配置加载现会明确报出冲突，切换及回退步骤已补入部署说明。`cd backend && go test -race ./internal/platform/config ./cmd/vera` 和 `make check-docs` 通过。

## 真实账号验收（2026-11-20）

在测试机单独启动同一份 TuShare 实现，使用独立 PostgreSQL、测试对象存储和已获准的真实模型配置。共享入口当时使用 Choice。证券名录、日线、估值、两融、行业成员和利润表返回真实记录。公告接口 `anns_d` 返回 40203。新闻 `major_news` 在分段分页全市场新闻时触发限频，首次同步整批失败。修正可选新闻的处理后，在既有限频及重试用尽时省略本批新闻并注明覆盖缺口，保持鉴权错误与其它采集错误的原有行为。修复后远端完成同步，发布 7,300 条记录。

贵州茅台近 20 个交易日资金动向由真实模型完成。最近收盘日为 2026-11-19，报告为 limited，5 页、24 条结论、3 张图，6 个数据集均归属 TuShare。抽查了 HTTP 证据详情及计算输入，并从工作台 API 导出 PDF，核对五页排版。持仓章节缺陆股通和公募持仓数据。个股分析、公司深研的真实计划均返回 REQUIRED_SECTION_UNAVAILABLE。下一步用有公告原件权限的账号验证三表披露版本、主营和风险正文，再执行其余两份报告。公开仓库仅记录验收范围，未上传真实报告、数据和凭据。

回归命令为 `cd backend && go test -race ./internal/dataservice/tushare`、`go test -race ./internal/app -run '^TestTuShareThreeReportDelivery$' -count=1`（同目录）和根目录 `make check-docs`，均通过。
