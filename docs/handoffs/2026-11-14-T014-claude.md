## 本次完成

### 1. Migration 00009：records 血缘字段

`backend/internal/platform/db/migrations/00009_records_lineage.sql`

向 `records` 表新增：
- `raw_ref text`：对象存储中原始响应的 key
- `raw_sha256 text`：原始响应体 SHA-256
- `raw_locator text`：JSON 路径或页码（指向 raw body 中的具体位置）
- `mapping_version int`：使用的 MappingSpec 版本
- `quality_state text NOT NULL DEFAULT 'PASS'`：CHECK（PASS/WARN/QUARANTINED/REJECTED）
- `revision_of uuid REFERENCES records(id)`：用于更正记录
- 索引 `records_quality`（部分索引，仅覆盖 PASS/WARN）

### 2. 类型扩展（`types.go`）

`Record` 结构新增血缘字段和 `QualityState`。

新增类型：
- `ErrClass`（RATE_LIMITED / AUTH_FAILED / NOT_COVERED / SCHEMA_CHANGED / UPSTREAM_UNAVAILABLE / EMPTY_VALID）
- `ProviderError`（携带分类的错误包装）
- `QualityIssue`（单字段/记录级质量问题，Fatal 标记决定是否 QUARANTINED）
- `MappingSpec` / `FieldMap` / `MappingBasis`（映射 YAML 结构体）

### 3. 映射加载器（`mapping.go`）

- `LoadMappings(dir)`: 递归读取 `<provider>/<dataset>.yaml`，返回 `map["provider/dataset"]*MappingSpec`
- `ApplyMapping(spec, raw)`: 纯函数，原始 JSON 对象 → 标准化 payload + quality issues
  - 支持 transform：`decimal`、`scale_to_base`（CNY_10K → CNY）、`date_yyyymmdd`、`string`、`integer`
  - 缺字段为非 fatal issue；transform 失败为 fatal issue → QUARANTINED
- `qualityStateFromIssues(issues)`: PASS / WARN / QUARANTINED
- 示例映射：`mappings/fixture/mkt_daily_bar.yaml`

### 4. 生产守卫（`guard.go`）

`GuardProduction(p Provider, production bool) error`：生产模式下拒绝 fixture provider。  
（config.go 已有同等检查，`guard.go` 供适配器层额外调用。）

### 5. Store 更新（`store.go`）

- `Sync` 写入新增的 5 个血缘列（`raw_ref`、`raw_sha256`、`raw_locator`、`mapping_version`、`quality_state`）
- `Query` 自动过滤 `quality_state NOT IN ('PASS','WARN')`，QUARANTINED/REJECTED 记录不进入研究快照
- `StoredRecord` 新增对应读取字段
- 新增辅助函数 `nilIfZero`
