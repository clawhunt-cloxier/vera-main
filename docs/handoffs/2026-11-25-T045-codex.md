## 实现

- 一轮对话由模型理解语义并提交一次已登记的 Tool Call。Go 校验标的及范围，Harness 按技能取得冻结数据和计算，展示报告、图表、明细及证据。工作台自动执行，已有待确认计划可按原流程继续。
- 问候和金融知识由模型选择回复类别和概念，服务端渲染已审定的文案。荐股、操作建议、投资评级、目标价、走势预测和收益承诺不在回答范围。混合问题可交付可核验的历史研究。中国大陆监管依据与发布前的资质核查记入 [发布规范](../RELEASE.md#financial-compliance)。
- 对话发起的准备作业与独立入口共享队列与同标的作业，独立入口的每日次数单独计数。数据库持久化轮次的模型发送次数，网关区分可计价的无效响应与用量不明的响应。
- `00027` 恢复旧密码登录缺失的列，仅在演示数据库按启动指南预配测试账号。应用回滚保留已有密码哈希。迁移与 OpenAPI 新增字段兼容说明见 PR。

## 本地验收

- 模拟环境使用 PostgreSQL 18、River、模拟模型与虚构行情。更新服务时保留原数据库、工作区和账号。`127.0.0.1:18097` 的 `/readyz` 返回 `ready`，`/app` 返回 HTTP 200。
- [对话验收命令](../../TESTING.md#conversation-acceptance) 的六个 Go 包均通过 race 检查。使用原生函数调用 HTTP 替身验证工具声明、自然语言场景、自动研究及引用。模型把新的日期范围误路由为查看旧报告时，服务要求澄清。
- `npm run test:conversation-ui` 在 1440×960 与 390×844 的本地部署上通过。验证密码登录、问候、概念追问、自动研究、图表、证据、原始公式、刷新历史、删除和旧客户端确认。`npm run test:realtime-ui` 的独立研报回归 20 项通过。
- 等待用户在浏览器验收。合并前记录对应实现提交、独立审查及 CI 结果。
- 真模型的自然语言覆盖、真实数据源、费用和时延未实测。后续接入 RAG、偏好、IM、专家和量化研究的边界见 [ADR-0006](../decisions/0006-conversational-research.md)。

## 回滚

回滚应用前停止接收新对话，排空或取消在途轮次和研究任务。保留向后兼容的迁移和已有报告。不执行会清除回复内容的 `00026 Down`。旧客户端仍可发送会话消息并确认计划。
