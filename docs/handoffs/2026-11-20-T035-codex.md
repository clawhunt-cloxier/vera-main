# T035 个股分析按简称或代码查找 A 股

Codex 于 2026-11-20T15:35Z 领取，分支为 `agent/codex/T035-any-a-share`，基线为 `f068765`。集成记录在 PR #45。

## 测试站复现

双来源部署中，个股分析对象框发出的普通 JSON 搜索只读取 TuShare 配置的收盘研究标的。在相同会话下，贵州茅台有候选，中国移动和中国石油均返回 200 及空列表。Choice 证券目录可查询沪深北简称和代码。实测其返回了中兴通讯、美的集团及贝特瑞。

## 实现范围

- 双来源个股分析按用户输入的证券简称或代码查询已授权目录。已登记的股票走原收盘研究流程，可在同一报告使用 Choice 的日成交补充。其余可由 Choice 覆盖的股票走 observation.v1 成交简报。计划、确认及读报告复用对应来源的权限检查。
- 本地模糊候选可能遮住尚未登记的精确名称。Choice 搜索现在按精确匹配优先合并候选，保留市场后缀与实体 ID。搜索服务故障时返回明确错误。
- 结构化选择不调用模型。自由描述入口沿用 Harness 的既有规则和可选 router，多个候选由用户选择。后续意图解析扩展可抽取证券名称原文，再由授权目录校验。
- 报告内容取决于该股票可获得的证据。成交简报提供有来源及日期的成交量、成交额和可用换手率。财务及资金动向继续按对应技能的数据要求判断。

- 后端回归覆盖 Choice 冷目录和模糊候选的合并、限定市场代码、登记范围及观察计划。网页回归通过对象框选择后分别检查创建计划和提交时的协议。
- 验证命令为 `go test ./...`、`npm run test:api-client`、`npm run test:realtime-ui` 及 `make check-docs`。PR #45 的 Verify run `44780143979` 于 2026-11-20T17:24Z 通过，CD run `44780143490` 于 2026-11-20T17:27Z 成功部署。
- 纯测试站 `https://vera.touziagent.com` 使用原生线上资源复验。中国移动 `600941.SH`、中国石油 `601857.SH`、贵州茅台 `600519.SH` 均能候选、创建计划、提交 `202` 并读取 evidence。前两者生成 Choice 成交简报，贵州茅台报告同时包含 TuShare Pro 与 Choice。另抽查美的集团 `000333.SZ` 与贝特瑞 `920185.BJ`，候选均正确返回。
