## 待验收边界

测试机在 2026-11-21 曾对 `anns_d` 返回权限错误 40203。本次使用项目测试密钥从开发机连接测试机时，SSH 未接受该密钥，运维探测命令未执行；当前公告订阅状态未知。可在已登录的测试容器运行 `vera admin provider test tushare --research`，记录五项接口状态，再决定能否做完整财报的真实验收。上述自动化用例使用模拟厂商响应和真实 PostgreSQL。

统一层的 `records.is_latest` 是遗留列，当前读路径以版本和截止时点确定可见记录。TuShare 规范化收盘记录保留原始档案定位与系统可用时间。已有 API 请求归档清单没有保存独立接收时间，通用证据接口继续省略未知的 `received_at`。补齐需要在采集时把实际接收时间与每条原始响应绑定。旧快照和报告按原编号保留，应用可独立回退。
