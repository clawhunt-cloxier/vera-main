## 实现与验收

- 个股分析和资金动向升级到 `1.0.3`，公司深研仍为 `1.0.2`；旧报告保留版本。新增账号可用时的龙虎榜每日覆盖、对应披露版本的原始席位证据、实际实施分红和按基金代码的持仓披露样例。Choice 与 TuShare 混合简报不变。
- 真实测试账号对 `top_list`、`top_inst`、`dividend`、`fund_portfolio` 的受控单页探测均返回记录。这不代替整批归档和工作台报告验收。现有账号调用 `anns_d` 返回 40203。官网 `disclosure_date` 提供日期而不提供年报正文、原文定位或足够的独立版次信息；现有 Choice 年报渠道也未验证可替代。用户需要在部署密钥中提供有公告权限的账号，且公告原文需可访问。不要将原始账号数据、密钥或报告提交到仓库。
- `go test -race ./internal/app -run '^TestTuShareThreeReportDelivery$' -count=1 -v` 使用合成协议上游与模拟模型：个股 51 条结论、4 张图、full；资金 23 条、3 张图、limited；公司深研 58 条、1 张图、limited。校验了四个新增证据表的 HTTP 读取、PDF、重放和撤权。最终分红修订集成后，`make verify` 中 app 测试通过，但同轮一个原有 Harness 期限测试因必需章节未在测试期限内完成而弃权，需单测和 CI 复验。
- 本版公募持仓不推导基金组合数量或市场汇总，陆股通季度持仓仍缺可验证的数据源。若新分红同时改了股权登记日且无跨版本方案 ID，不能推断其与旧事件相同。接口缺数不作为未发生的证明。
