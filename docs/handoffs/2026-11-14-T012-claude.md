## 本次完成

### 1. Docker Compose 开发环境 (`docker-compose.yml`, `Caddyfile.dev`)

- Postgres 17-alpine：端口 5432，数据库 vera_dev
- MinIO RELEASE.2024-11-07：端口 9000/9001（对象存储）

- Caddy 2.8.4-alpine：端口 3000（主入口），8081（Keycloak admin 代理）
- 所有服务含 healthcheck，Makefile 目标 `dev-up`/`dev-down`/`dev-migrate`/`test-integration`

### 2. 迁移 00007：数据模型缺口

补齐以下缺失表：
- `usage_ledger`（FK model_calls，UNIQUE call_id）
- `publications`（FK report_versions，permalink UNIQUE）
- `raw_objects`（FK providers，UNIQUE provider+dataset+key+hash）
- `record_conflicts`（部分索引 WHERE resolved_at IS NULL）
- `snapshot_items`（FK snapshots + records，ON DELETE CASCADE）
- `fact_sheets`（FK research_tasks，UNIQUE task_id，jsonb sheet）

### 3. 迁移 00008：缺失约束与索引

- `watchlist_alerts` 表（item_id + alert_type UNIQUE）
- `model_calls.epoch` 列（bigint NOT NULL DEFAULT 1）
- 组合 FK：`model_calls(task_id, epoch, step_key)` → `task_steps` DEFERRABLE INITIALLY DEFERRED
- 索引：task_events_epoch、claims_section、sessions_workspace（部分）、oidc_logins_expires、capabilities_dataset

### 4. sqlc 配置 (`backend/sqlc.yaml`)

- schema 指向 migrations 目录，queries 目录 `internal/platform/db/queries`
- 输出到 `internal/platform/db/dbgen`，pgx/v5 引擎
- uuid → `github.com/google/uuid.UUID`，timestamptz → `time.Time`

### 5. 集成测试 (`backend/internal/platform/db/integration_test.go`)

- build tag `integration`，依赖实际 Postgres 实例（需 `VERA_TEST_PG_DSN` 环境变量）
- TestDatabaseSchema：验证所有预期表存在、RLS 已启用、FK 约束存在
- TestBasicCRUD：创建 user + workspace 验证基础写入
