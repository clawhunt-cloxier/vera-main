# ADR-0005：单股真实数据研报演示

状态：2026-11-15 用户授权的优先交付范围；尚未实现或验收。该演示不替代 ADR-0003、ADR-0004 的完整技能或 V02 数据覆盖要求。

用户在测试网站选择或输入一只 A 股，经确认计划后生成简版研报。必需部分为真实授权的行情快照、证券身份、数据时点与来源；可核实披露时间和版本的公司及最新可用财务事实可以加入，无法核实的可选数据明确列出缺失。采用已配置的 DeepSeek Flash 模型，输出仍须遵守证据绑定、确定性校验和 ADR-0003 D2 禁用表达规则。不得混入 fixture、使用模型记忆补数或将报告期当作披露日。

用户要求盘中实时数据。只有账户权限、行情事件时间语义、时区及延迟性质经验证，且行情满足新鲜度规则时，才能标识实时；未知或过期行情必须明确不可用，不能用收盘价或模拟数冒充。厂商账户及数据处理用途仍须按已确认授权和受控产品配置执行。

冻结截止时间、实际行情事件/接收/可用时间及其他数据的实际披露或期间分别展示；任务重试使用原快照，必需证据缺失时明确弃权。测试网站现有模拟样例仍应清楚标记，其数据不能进入真实演示报告。

验收包含：真实 SDK 与测试网站端到端运行；交易时段验证实时权限、事件时间和新鲜度；至少一份报告的每个数字可定位至原始归档或确定性计算；无权限、过期、缺失、模型失败和重试均不伪报成功；密钥仅来自受控服务器配置。部署使用 dev 的 CI/CD，验证最终运行镜像和网站行为。

## 2026-11-15 休市交付补充

用户明确允许休市真实简报、盘中另验实时，并要求未验明的 Choice 字段保留待办。新增独立版本 `1.1.0-demo.2`：使用当前采集并归档的证券身份和已确认单位的日成交量、成交额、换手率观察值生成 limited 简报。请求区间及厂商返回日期不等于披露时间；报告明确展示采集与冻结时点，不声称历史 PIT、完整日线或实时。行情 TIME、状态、延迟及财报版本未验明时不进入本版本模型事实。它不更改 `demo.1` 的 realtime_trade 门槛，不回退 fixture。盘中实时接入继续按原验收执行。

本版本仍须当前存储/模型/展示用途授权、原始归档回读、任务快照绑定、确定性核验和取消/重试保护。不可验证日成交数据时明确弃权。
