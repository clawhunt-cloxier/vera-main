# ADR-0006：工作台对话流研究

状态：T044 交付方案。基线为 `dev@f21e2b0`。

## 产品流程

- 认证工作台增加对话输入和私人历史。用户在会话内澄清标的、确认计划、查看进度和结果。首页保留正式研报、自选股及历史任务入口。
- 首批支持 A 股单证券的日成交与融资余额。每轮短研究展示已核验结论、数据表、图表、口径、实际覆盖、数据截止和证据。只开放部署当前已登记的数据和技能。需要其它完整研究时，使用现有研报计划与报告入口。
- 新问题继承唯一的已确认范围。明确的新标的、窗口或主题更新范围。解释、来源和公式使用指定轮次的交付版本。新取数、新计算与完整研报继续要求计划确认。歧义和超出能力登记的请求在会话内说明。
- 沿用 [ADR-0003](0003-product-harness-runtime.md) 的 D2 输出边界、D8 计划确认及 [Harness](../HARNESS.md) 的确定性约束。已核验后一次性交付研究正文。任务进度先使用可恢复的轮询。

## 接入方案

会话由 Go 服务管理，React 通过同源 JSON 接口发送消息与动作。PostgreSQL 保存会话、轮次、已确认范围及计划或任务引用。工作区由认证上下文确定，私有表使用 RLS 和复合外键。业务命令用唯一键和轮次版本处理重试。计划、轮次和任务绑定使用事务，River 任务状态是终态及可用报告的依据。

Harness 为短研究登记版本化范围，按主题限定数据、窗口、计算、章节和预算。既有 Choice 成交简报可在其已支持范围内使用。使用现有目录、快照、公式和交付核验。会话通过报告 ID 和版本重新读取结果、图表和证据，沿用当前来源授权。历史列表保存会话信息与引用。会话默认保留 90 天，删除或到期后停止显示并处理在途任务和会话专有数据。独立完整研报按原留存规则管理。

在上下文装配处保留 RAG 摘要、上下文引用和偏好装配的接入位置。它们受 workspace 隔离、来源用途、删除和保留期约束。专家及量化研究随 Harness 的技能版本登记扩充，取数和计算由受信代码执行。会话命令接收受信 principal 与渠道身份，未来 IM 可经显式账号绑定、外部消息去重和用户确认使用相同服务。首版接入网页。

首版用有界规则与目录解析问句。常用的交易日追问可继承上下文，陌生简称或未登记代码通过现有证券搜索确认。该流程不调用模型来猜测意图、对象或数值。原研究解析器继续服务正式研报入口。

对话按现有技能调用财务、资金与行业场景的研究流程。多个专家共同研讨、量化计算、RAG 摘要、用户偏好与 IM 适配仍按各自的数据与评测要求演进。未来接入点分别是 Harness 技能版本登记、会话上下文装配与身份认证后的会话命令。

## 实施计划

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 1. 冻结接口和数据模型 | 会话、轮次、计划绑定、结果投影、数据留存和权限契约 | 增量迁移可重放，OpenAPI 校验及生成类型通过。 |
| 2. 接通 Harness | 日成交、融资余额、短报告、幂等确认和取消 | 实际任务和快照交付，覆盖缺数据、禁用表达及可回溯的数值与序列。 |
| 3. 接通工作台 | 新会话、历史、多轮追问、范围确认、报告证据 | 桌面与手机端从首页完成查询、刷新、续问、核对证据及转完整研报。 |
| 4. 验收与交接 | PostgreSQL、River、浏览器、原研究协议和 PDF 回归 | 验证隔离、重复提交、撤销权限、任务恢复、删除及原报告兼容。记录数据模式和实测限制。 |

真实环境需与 [RELEASE](../RELEASE.md) 的发布条件一起验收。部署方提供有效数据和模型凭证后，分别记录已准备及初次准备证券的时延、来源覆盖和费用。
