## 首版资源参数

上传入口不开放。连接器下载最大25MiB/文件、PDF最多300页、解析单次120秒；超限返回明确不支持，不静默截断关键证据。扫描PDF/OCR、加密PDF不支持P0；允许以后通过新解析适配器增加能力。每批数据库写入<=500条，进一步按压测调小。

任务deadline从创建时计时，包括排队；P95研究指标从准入后计时，另报告排队延迟。任务并发与模型并发分开计数；调用预留按上限、返回后按实际usage核销；未知外部调用继续占保守预算直到核对或期限。

原始数据保留币种和单位；展示单位按指标确定，禁止跨币种直接聚合；采用十进制half-up在最终显示舍入。比较公式输入不提前舍入。对账不能把币种/口径错误当容差问题。各指标误差上界及NA语义由T004/T005固化到字典，不再引入未经测量的统计删除门限。

## 为什么采用此方案

用户已明确确认首版采用单个研究 Agent。先完成有依据的研究路径和网站体验；后续对照单 Agent 基线评测多 Agent 的质量、成本与延迟，确认收益再决定是否加入研讨。模板、数据版本、权限和Operation台账保留扩展边界，但不为P1/P2提前建设额外服务。生产外部条件见RELEASE；代码开发不因此暂停。
