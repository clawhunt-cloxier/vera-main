# 技能：自选股 watchlist v1.0.0

对应原项目 `stock-watcher.md`。自选股是用户私有的状态，不调用模型。它把研究结果和日常跟踪连在一起，替代原系统里“分析后问是否加入自选”和“研究前检查历史”的对话流程。

## 1. 功能

| 功能 | 行为 |
| --- | --- |
| 添加/移除 | 通过实体搜索或报告页按钮添加 A 股个股；可选标签（≤5 个，每个 ≤10 字）和备注（≤500 字）|
| 列表 | 每行显示：名称代码、最新收盘价、当日涨跌幅、区间涨跌幅（添加以来、近 20 日）、PE(TTM)、融资余额 5 日变化、最近一份报告（技能、日期、链接）、触发的提醒 |
| 提醒 | 价格上穿/下破、单日涨跌幅超过阈值、融资余额 5 日变化超过阈值、有新定期报告或业绩预告公告；收盘后计算，站内显示 |
| 研究历史 | 每只股票显示该用户已完成的报告列表；发起新研究时提示上次报告的日期和技能 |
| 快捷研究 | 从列表一键创建个股分析或资金动向的研究计划，仍需确认 |

## 2. 规则

- 每用户最多 100 只股票、每只最多 5 条提醒。
- 快照由 `watchlist.snapshot` 作业在交易日收盘数据可用后计算，使用与研究相同的统一数据集；不触发厂商额外请求（公共数据已按交易日缓存）。
- 提醒只陈述触发的事实（“收盘价 X 元，低于设定的 Y 元”），不给建议；原项目“涨跌超过 3% 时搜索新闻解释原因”的做法取消，因为会把新闻相关性写成因果。
- 首版提醒只在站内显示，不发邮件或消息推送。
- 删除自选股不删除历史报告。

## 3. 数据

表 `watchlist_items`：`workspace_id`、`entity_id`、`tags`、`note`、`added_at`、`added_price`（添加时最近收盘价，记录 trade_date）、`version`。

表 `watchlist_alerts`：`workspace_id`、`item_id`、`kind`（`price_above`/`price_below`/`daily_change`/`margin_change`/`new_filing`）、`threshold`、`enabled`、`last_triggered_trade_date`。

表 `watchlist_snapshots`：`workspace_id`、`trade_date`、`item_id`、指标值、`triggered_alerts`、`snapshot_hash`。

## 4. 验收

- 两个用户的自选股、提醒和快照隔离。
- 停牌、退市、更名时列表正确显示状态，提醒不误触发。
- 价格阈值在除权日使用不复权价判断，并在提醒中注明。
