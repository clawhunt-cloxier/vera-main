# 真实成交数据简报

版本：stock_analysis / 1.1.0-demo.2。范围依据 [ADR-0005](../decisions/0005-real-data-demo.md) 的休市补充；不替代完整 stock-analysis 技能。

- 输入：已配置且当前用途授权的单个真实证券身份；用户确认计划。研究参数为空；证券和字段白名单仅部署侧决定。
- 数据：Choice NAME/LISTDATE/DELISTDATE 原始归档用于身份核对；模型只使用已确认单位的 VOLUME、AMOUNT、TURN。请求采集日前一日向前四十五自然日，表格展示最后取得的至多二十个日期，模型只用最近三个日期生成重点，缺失日期不补值。
- 时点：日期是厂商序列期间标签；当前观测不保证历史 PIT，不等于首次发布时间。模型不获知未验明的 TIME、状态、延迟和财报版本。
- 章节：S1 核心要点，S2 已取得日成交数据（必需），S3 实时行情与财务数据（缺失，明确说明）。输出 limited、非实时；S2 只允许通过现有数字/引用/禁用表达规则的事实。禁止价格预测、操作建议与无依据推断。
- 来源：对象存储内容寻址归档、许可登记、任务绑定清单；重试复用原清单。模型和展示分别重新授权；取消、过期、归档损坏、许可撤销阻止继续使用。

验收样例：真实成交观察生成 limited；跨 workspace 读取拒绝；许可撤销拒绝；重复确认/执行只交付一次；对象损坏、缺必需数据和无效模型输出不交付。自动化入口：`go test ./internal/app -run TestObservationBriefDelivery`；真实环境显式 `VERA_LIVE_BRIEF=1` 运行 `TestLiveObservationBrief`，需真实 SDK、持久 S3、许可与模型配置，消耗真实额度，结果不入 Git。
