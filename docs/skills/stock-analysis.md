## 1. 输入

### 收盘研究版本 1.0.3

S8 在“已披露现金分红实施明细”逐笔列出所属报告期、实施公告日、派息日和税前金额。数据来自 TuShare `dividend`，每十股派现取 `cash_div_tax × 10`（元），本次基准股本取 `base_share × 10000`（股）。折算派现金额的计算记录保存同一实施方案的两项输入。方案须有已公开的实施公告、到期派息日、可核验的现金金额和参与分配股本。不同期间、不同登记日的方案可分别使用各自的股本，年内覆盖情况见报告限制说明。

研究时按证券、来源、所属报告期和股权登记日核对最新实施公告。如果更正公告延后派息、撤销现金分配或缺少基准股本，该笔金额从后续报告中移除。已冻结报告保留当时的披露版本。

评测中，同属 2025 年的两次派息分别依据 1,000 股和 990 股折算，明细分别列示 320 元和 544.5 元。更正公告按同一登记日保留最新已公开版本。龙虎榜披露席位按原文列示，席位之外的投资者身份和全市场机构交易量属于覆盖缺口。

### 收盘研究版本 1.0.2

分部表及收入占比采用截止时点最新年度公告的分项。评测先登记原年报 A，再登记更正年报 B，验证 A 的分项从新报告及占比分母中移除。缺少公告标识、同一披露时刻存在多份候选、最新年度尚无对应分项时省略分部表。历史报告保留冻结时的版本。

TuShare 已登记的研究标的使用固定截止时点。行情使用交易日历、个股复权收盘价、沪深 300 及已映射的申万指数。相对收益按共同有效交易日计算。同期财报、申万分类、年报业务段落、股东事项与近 30 天的公告或新闻分别决定章节可用性。报告来源逐数据集显示供数方。

计划读取数据库已发布批次后的截止时点。收盘行情与估值使用最近已结束的交易日，允许上一个交易日的值，并在正文标注实际收盘日期。交易日历无法覆盖近期或行情超出此窗口时，行情章节不可用。连续休市按已接入交易日历判断。

收入按产品披露为 30 和 70，另按地区披露为 100 时，第一个产品占产品维度已披露收入的 30%。只有半年度分部数据时省略年度表格，缺复权因子时图上留空。[收盘研究评测](../../backend/internal/harness/close_research_test.go)

## 4. 公式

盘中快照不代替完整日线或收盘指标；未实现、无权限、延迟或过期须按计划明确 unavailable/limited，用户明确要求实时且必需快照不可用时弃权。

财务公式沿用旧年度模板 F01–F08（金额变化、正基数同比、毛利率、百分点变化、现金利润差、现金利润比、资产负债率、分部收入占比），并新增：

| ID | 计算 | 适用条件 |
| --- | --- | --- |
| F09 roe_simple | 归母净利润 / 平均归母净资产 | 平均归母净资产 > 0 |
| F10 nonrecurring_share | (归母净利 − 扣非归母净利) / 归母净利 | 归母净利 > 0 |
| F11 goodwill_to_equity | 商誉 / 归母净资产 | 归母净资产 > 0 |
| F12 period_return | 区间末复权收盘价 / 区间初复权收盘价 − 1 | 区间内至少 80% 交易日有数据 |
| F13 excess_return | F12(个股) − F12(基准) | 两者同区间 |
| F14 max_drawdown | 区间内复权价相对前高的最大跌幅 | 同 F12 |
| F15 percentile_rank | 当前值在历史窗口内的百分位（不含负值 PE，负值单列）| 窗口内有效样本 ≥ 60% |
| F16 peer_median_rank | 可比公司中位数与本公司排位 | 有效可比公司 ≥ 5 |
| F17 avg_daily_amount | 区间日均成交额 | 同 F12 |
| F18 balance_change | 期末余额 − 期初余额（融资余额、持股数等）| 两端均有值 |

公式输入不提前舍入；展示规则：金额亿元两位小数、比例两位小数、倍数两位小数。

## 5. 写作约束（技能级）

- 每章节最多 6 条结论，每条不超过 120 字；细节放在表格中，表格由模板根据事实表渲染，不由模型生成。
- S5 估值：只允许陈述“处于近 N 年 X% 分位”“高于/低于可比公司中位数”；禁止“低估/高估/合理/便宜/贵”。
- S7 资金面：交易所披露的数据（融资、龙虎榜、大宗、陆股通季度持股）可作为事实；厂商资金流必须写明“按某厂商大单口径”；禁止“主力”“游资”“机构抱团”等未定义标签。
- S10 情景：最多 3 条。每条格式为“若 [可观察条件]，则 [受影响的已知指标] 可能 [方向]；观察 [事实 ID 对应的指标]；若 [条件] 则该判断不成立”。禁止概率、价格、时间预测。
- 研报评级和目标价（`research.report_meta`）不进入本技能的事实表。

## 6. 验收

- 固定 fixture 公司在 full、缺 S7 数据（limited）、缺 fin.statement（ABSTAINED）三种情况下按规则判定。
- 负净利润、亏损转盈、ROE 分母为负、PE 为负、停牌导致区间数据不足时，公式按适用条件返回 NOT_APPLICABLE，正文不出现误导的增长率或分位。
- 对抗样例：在事实表注入“建议买入”文本、在新闻中注入指令、让模型输出目标价，都被规则删除，且不影响其他结论。
