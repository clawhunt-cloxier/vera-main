# 研究入口与范围

状态：当前规范（ADR-0003 D1、D8），取代 ADR-0002 的 `general_research` 通用模板。本文规定用户如何提出研究需求、系统如何把需求变成可执行的计划，以及首版支持的对象范围。各技能的章节与数据见 [skills/](skills/)。

## 1. 研究对象

| 类型 | 首版范围 | 说明 |
| --- | --- | --- |
| `stock` | 沪深北交易所上市的 A 股 | 包括亏损公司；ST、退市整理期股票标注状态。金融类公司（银行、保险、券商）在财务章节使用专用指标前，相关财务章节标为 unavailable |
| `industry` | 申万一级、二级行业 | 分类版本随实体登记，成分按 as_of 当日确定 |
| `market` | A 股全市场 | 仅资金动向技能使用 |

实际可研究的对象与时间范围以数据服务的能力登记为准（[DATA_SERVICE](DATA_SERVICE.md) §10）；厂商未定之前不宣称覆盖。

## 3. 从一句话到计划

解析规则见 [HARNESS](HARNESS.md) §3。对用户的行为要求：

- 一句话中可能包含多个对象或多项需求（“对比茅台和五粮液”）。首版每个任务一个对象一个技能；系统列出拆分建议，由用户选择创建哪几个任务。
- 系统不支持的需求（如“给我推荐几只股票”“明天会涨吗”“目标价多少”）直接说明不支持的原因，并给出可以做的替代研究（例如对指定股票做个股分析），不创建任务。
- 时间表述解析为交易日窗口；超出数据覆盖时提示并给出最大可用范围。
- 用户输入只用于解析和作为深度研究的 `focus`，不进入系统规则，也不改变数据范围。

## 4. 计划确认契约

- `POST /api/v1/research-plans`：请求为 `{text}` 或 `{skill_id, subject_id, params}`；返回计划或候选列表。不提交任务或调用厂商接口（只读能力登记与统一层缓存状态）。
- `POST /api/v1/research-tasks`：请求为 `{plan_id, plan_hash, disabled_sections}`；校验通过且队列容量允许后，原子地创建任务并入队。
- 计划 30 分钟过期；过期或能力登记变化导致 `plan_hash` 不匹配时返回 409，前端重新生成计划。

字段定义见 [contracts/openapi.json](../contracts/openapi.json)。

## 5. 报告版本与重新研究

- 任务完成生成报告版本 1。首版不对已交付报告做修订；数据更正后用户重新发起研究，得到新任务和新报告。
- 报告冻结：技能版本、计划哈希、数据快照哈希、规则集版本、提示词版本、模型 profile 与实际模型版本。
- workspace 首页和自选股展示同一对象的历史报告，便于对比；首版不自动生成“与上次相比”的增量内容。

## 6. 与旧模板的关系

`annual_financial_review`（年度财报点评）与 `general_research`（通用研究）不再作为入口。年度模板的 F01–F08 公式和财务口径规则并入个股分析与深度研究的财务章节；其模拟样例与 `tests/fixtures/annual-review.json` 继续作为公式回归样本。
