# 研究范围与通用报告

Vera 是金融投研 Agent；网站是交互入口，试用是发布阶段。用户选择个股、行业或其他金融标的，并提出研究问题。首版采用单个研究 Agent，数据治理、证据校验及预算控制保持不变。

## 选择与能力检查

主体目录登记 kind（stock/industry/other）、asset_class、市场、代码或行业分类体系及版本。other 用于基金、指数、债券等可扩展类别，不表示任意对象均已接入。行业必须固定分类体系、成分范围和时点。厂商未定，不能预先宣称全市场覆盖。

前端允许按名称、代码和类别搜索，显示覆盖期间与可研究状态。用户提交 entity_id、research_question、time_range、research_as_of。服务器验证对象已覆盖、起止日期有序且不晚于截止时点、问题非纯空白、数据权限与能力；明确不支持返回422并说明原因。不得自动替换为另一对象或年报任务。

创建后按问题生成有界研究计划，持久化数据需求、必需/可选证据、指标及选择理由。规则检查计划是否可执行，再冻结计划版本供治理与验证共用。模型不能为了通过验证删去原问题的必需证据；修订计划留版本并重新检查。证据不足明确弃权或提供符合已冻结可选项规则的受限报告。

## 通用模板 general_research v1.0.0

| 章节 | 内容 |
| --- | --- |
| S0 | 研究对象、用户问题、时间范围与截止时点 |
| S1 | 结论摘要及关键依据 |
| S2 | 数据范围、来源与覆盖缺失 |
| S3 | 与问题相关的主要发现 |
| S4 | 适用指标、计算与比较口径 |
| S5 | 风险、反向证据及未解决问题 |
| S6 | 引用、方法与限制 |

关键事实和判断绑定证据，计算绑定公式与输入版本。无适用计算时说明原因，不强制填财务指标。行业聚合保存成分、权重、分类版本和缺失情况，不能直接平均不同比率或混用币种。年度财报模板和模拟算术夹具只用于对应场景，不自动成为每份报告的覆盖要求。

验收覆盖个股、行业和至少一种其他金融标的，每类至少5个案例、总计至少30例；真实接入前先完成模拟适配与契约。数据厂商仍留空，实际类别、市场和范围由采购后的能力登记确定。
