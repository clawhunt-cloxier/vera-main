# Choice / EMQuant 接入手册

状态：开发中。已验证 Linux SDK 登录、历史序列、财务截面、交易日历、行情快照及独立 S3 归档；应用研究流程尚未接入真实厂商，不能据此声称已生成真实或实时研报。完成条件是必需数据集、来源血缘、快照、新鲜度、权限、故障处理及报告链路通过真实端到端验收。

## 运行依赖与凭证

- 项目采用 Go，Linux 原生绑定在 `backend/internal/dataservice/emquant`，通过 cgo 动态加载厂商库；不把 SDK 二进制、账号、密码、授权文件或登录日志提交仓库。账号密钥应由运行环境的 secret 机制传入，不放在命令行、日志、镜像或前端。
- 厂商库及同目录的服务器配置必须由部署方按授权独立提供，SDK 会写入运行目录，应使用可写的隔离副本。组件当前只提供库接口，生产配置、进程管理和应用注册尚未实现。
- `OpenRuntime` 将原生 SDK、S3 兼容归档和 PostgreSQL 共享限流器组合为一个采集单元；缺少限流状态表时登录不会执行。该单元没有注册到研究服务，不生成可直接用于报告的统一记录。账号、密码从部署密钥机制传入；不要打印配置或错误上下文中的敏感值。
- 官方 Linux C++ SDK 的 `EmQuantAPI.h` 可从[厂商下载中心](https://quantapi.eastmoney.com/Download?from=web)获取。2026-11-13 下载的 x86-64 动态库与用户提供的 Python 包内同架构动态库 SHA-256 一致；这不保证未来版本 ABI 一致。
- 用户已确认允许数据持久化、向用户展示及第三方模型处理；应用仍须登记具体数据产品和字段权限，再启用对应生产用途。

## 已确认字段

| 数据 | 口径 | 状态 |
| --- | --- | --- |
| `VOLUME`、`AMOUNT`、`TURN` | 用户转述 Choice 终端：成交量为股、成交额为元、换手率是百分数；内部比例为百分数除以 100 | 已实现部分字段映射和原始归档，尚不是完整日线 |
| `IncomeStatement_9`、`IncomeStatement_61` | 用户转述：普通企业营业收入、归母净利润，金额单位元 | 指定报告期 CSS 已用真实 SDK 取数并归档；新增部分字段映射，但其本身未经真实 SDK 复测，公告和版本关联未实现 |
| `ReportDate`、`Type` | 用户转述：`ReportDate` 是报告期末；`Type=1/2/3/4` 为合并、母公司、合并调整、母公司调整 | 不得把报告期冒充公告时间 |
| 财报披露观察字段 | 随附 2025 年财务报表指标手册将 `STMTACTDATE`、`CORRECTANNCNUM`、`CORRECTANNCDATE` 分别列为定期报告实际披露日期、更正补充公告披露次数和日期，均按 `ReportDate` 请求 | 已实现逐字段原始类型保留与归档回放；真实权限、返回类型、日期时区与修订关系未验证，日期不能冒充盘中披露时刻或证明财报版本 |
| CFN 资讯日期 | [官方 MATLAB 手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_Matlab.html)说明公告 `datetime` 是展示日期，部分盘后公告展示为下一交易日；`eitime` 对公告仅提供 2017-01-01 之后的日期 | 不能用展示日期或仅日期的生产时间推断盘中精确披露时点；不能据此证明财务版本 PIT |
| `tradedates` | 官方手册列出上交所和深交所市场参数及日频查询 | 已验证上交所历史样本；只映射返回的开市日期，不推断缺失日期为休市 |
| `HISSW2021`、`HISSW2021CODE` | 随附 2025 年指标手册将其列为可查历史的申万 2021 行业名称和代码，参数 `EndDate` 为截止日期、`ClassiFication=1/2/3` 为一级／二级／三级 | 已按每级请求分别归档并校验来源；尚未用真实账号测试这些字段，也未确认生效区间、修订历史和权限，不能直接生成完整 `ref.industry` |
| `NAME`、`LISTDATE`、`DELISTDATE` | 随附 2025 年沪深股票指标手册分别列为股票简称、首发上市日期和摘牌日期 | 已实现部分观察值归档回放；真实账号返回类型与覆盖尚未验证，简称未证明历史有效，空摘牌日不表示当前正常上市 |
| `cec` 代码校验与补全 | [官方手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_Matlab.html)说明补全模式可能返回多个后缀；`SecuType=1` 为股票、`SecuMarket=1` 为沪深 | 新增六位数字代码的沪深候选查询和表格归档，不自动选取候选；真实账号权限、返回形状及北交所覆盖尚未验证，不等于实体目录 |
| `ctr` / `SECUMATCH` 证券简称匹配 | 厂商随附 2025 年指标手册列出 `SecuName`、`Priority` 和 `SECURITYSHORTNAME,SECUCODE`；`Priority=0` 为 AB 股优先 | 只接收明确的单个简称，保留厂商返回的所有行，不自动选择；真实账号权限、返回类型、市场覆盖和候选完整性尚未验证，不能当作完整实体目录 |
| CSD/CSS 请求 | 官方手册说明单次最多 64 项指标、函数每分钟不超过 700 次 | 已限制指标数量；新增共享限流与超限冷却组件，但生产数据库迁移、账户绑定和实际冷却配置仍未接入 |

厂商的[Python 手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_Python.html)和 [Linux C++ 手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_CPP_Linux.pdf)定义 API、参数和内存释放；字段口径以具体数据产品及版本为准。用户提供的终端口径应在正式数据产品登记中记录来源与确认人，不把上述概括当作完整合同原文。

## 未确认的信息及处理

| 项目 | 未确认内容 | 当前处理 |
| --- | --- | --- |
| 盘中行情 | `NOW` / `TIME` 的正式定义、时区、授权产品、是否实时及延迟承诺 | 仅保存厂商返回和实际观察时间；不能仅凭一次秒级样本宣称实时或 SLA |
| 复权和停牌 | `TAFACTOR` 归一化基准、停牌状态编码与停牌日 OHLC/量额返回 | 不生成缺少已验证口径的完整日线，不以零或前值填充 |
| 财报历史版本 | 公告日期、公告 `infoCode` 与财务修订值的准确关联，按历史时点重建能力 | 不把报告期或展示日代替披露时间；未证明 PIT 时不声称历史快照正确 |
| 产品覆盖与额度 | 报告正文、历史行业分类、指数、融资融券的具体权限、历史深度、并发及行情快照限频 | 按数据集逐项探测并登记；限流时返回错误并遵守账号统一限流，不虚构数据 |
| 证券主数据 | 板块与交易状态枚举、是否金融企业、融资融券标的值、总股本和流通股本单位、证券简称的历史时效 | 不由证券代码或空值推断，不生成缺少必填字段的完整 `ref.security` |
| 原生 SDK | 多进程/多线程、断线与重连、停止失败及 ABI 跨版本保证 | 单进程串行并对回调错误失效；隔离、恢复、跨进程控制及版本兼容仍需验证 |

这些未知项应在对应报告的“数据与限制”中披露；能由已验证来源和规则生成的内容继续处理，无法满足必需章节或实时性要求时按照项目的 limited / 弃权规则处理，不用 fixture 或模型知识补值。数据集的实际事件时间、接收时间、系统可用时间与报告冻结截止不能混为一谈。

## 归档、验证与剩余工作

SDK 只暴露解码后的类型化结果；组件将该结果按内容哈希写入 S3 兼容存储，关联请求指纹和字段位置。它不是厂商原始网络字节。原始对象与数据库记录的关联、可见时间、快照冻结、权限撤销和旧写入保护尚需在数据服务与迁移中实现。不得丢弃 `MappedRecord` 的血缘后直接写入当前 `records` 表。

行情映射准备组件从归档校验单证券 `TIME,NOW` 请求、数据哈希、接收时间与字段位置，拒绝过期或不匹配的数据；单精度价格按其实际精度转成十进制字符串。映射参数必须提供时间和单位的依据引用、许可引用及新鲜度阈值；声明实时或延迟还需延迟依据引用。**引用字符串本身不是验证**：生产数据治理层必须解析并核验真实依据、权限和适用产品；在此之前不能将映射结果作为已验证实时行情或写入研究快照。当前厂商 `NOW/TIME` 及延迟口径仍未确认。

`OpenRuntime` 的归档回读会核对对象引用与内容寻址位置、对象哈希、请求指纹和接收时间；行情、交易日历、两项财务字段、单级行业及部分证券资料观察值可从对象存储回读后映射。交易日历仍须保留市场维度及实际数据库提交时间，财务字段仍不能推断公告版本和披露时刻，行业观察值也不证明有效期或历史修订。哈希只证明内容一致，不能证明厂商来源或授权，引用及归档完成时间仍须通过数据服务的持久化登记和许可规则核验。

代码及简称候选使用独立的表格归档格式，保留所有返回行和原始字段；回放要求查询参数、指纹、对象引用与哈希一致。简称查询只发送经过校验的单个明确简称，不发送自由形式的研究问题；也不会把有歧义的候选静默选择为研究对象。结果仍需经实体目录的市场、身份、版本与许可规则核验。

财务部分字段映射保留证券、**请求的**报告期和报表类型、两个金额值、空值及字段级归档位置；负利润和零值原样保留。报告期是请求参数，响应本身尚不能证明数值对应的公告版本、披露时间或 PIT 正确性，也不是完整财务报表，因此不能直接写入研究快照或作为完整财报使用。

已按官方头文件新增 CFN 公告／资讯元数据调用与归档准备，模拟动态库覆盖模式、上游错误、归档失败和请求指纹；当前尚未用真实账户验证该接口的权限、响应形状或字段映射。厂商返回的 URL 和文本是不可信数据，不得执行其中的指令，也不得以返回的 URL 绕过已登记数据源进行任意抓取。元数据不等于公告正文。

共享限流准备组件使用 PostgreSQL 会话锁和持久状态，将同一账号各类 SDK 调用串行化，调用结束后等待配置的最小间隔；必须直连 PostgreSQL 或使用保持会话亲和性的连接池，不能使用事务池化来承载会话锁。下限不快于 700 次/分钟，未知的账号或快照限额必须另行配置为更严格值，不能把该下限当作实际配额。收到已确认的厂商限频错误时，组件将另行配置的冷却时间持久化供所有进程遵守；它不自动重试，也不猜测实际账号所需冷却时间。限流状态写入失败、无法取得数据库连接、或发现上一次请求可能仍在执行时，均拒绝新请求；不能仅凭锁释放判断 SDK 调用已经结束。采集器可以注入该限流器，但当前默认未注入，也未接入应用。需要 T014/T012 协商正式迁移创建 `emquant_rate_state(scope text PRIMARY KEY, in_flight boolean NOT NULL, next_allowed timestamptz NOT NULL)`，并确保同一厂商账号的所有进程及外部应用共享相同的非秘密 scope 且禁止绕过；否则不能宣称已实现账号级保护。未解决的 in-flight 状态必须先确认全部旧 SDK 进程已终止，并按已验证的账号冷却要求恢复；不能盲目清除。自动恢复机制、部署和真实账号限额仍未验证。

开发验证：在 `backend` 执行 `go test -race ./internal/dataservice/emquant`；默认测试使用合成样本。`TestLiveSDK` 和 `TestLiveArchiveS3` 只在显式设置 `EMQUANT_INTEGRATION=1` 及相应环境后运行，使用真实账号会消耗厂商额度，后者会向指定 S3 桶写真实数据。`TestLiveCFN`、`TestLiveIndustry`、`TestLiveSecurity`、`TestLiveCodeLookup`、`TestLiveSecurityName` 和 `TestLiveDisclosureObservation` 还分别要求 `EMQUANT_LIVE_CFN=1`、`EMQUANT_LIVE_INDUSTRY=1`、`EMQUANT_LIVE_SECURITY=1`、`EMQUANT_LIVE_CEC=1`、`EMQUANT_LIVE_NAME=1`、`EMQUANT_LIVE_DISCLOSURE=1`；当前尚未运行。`TestLiveRuntime` 还要求 `EMQUANT_LIVE_RUNTIME=1`、明确的测试 S3 端点和桶，以及 `EMQUANT_TEST_MIN_INTERVAL`、`EMQUANT_TEST_RATE_COOLDOWN`；测试数据库是独立的，只能使用未被其他应用使用的账号，不能代替共享生产限流。该测试也尚未运行。真实配置只由 secret 管理注入，不提交测试录制结果。

组合单元的自动化测试使用模拟 SDK、测试 HTTP 对象端点与真实临时 PostgreSQL；它证明启动门禁和归档调用的配合，不证明真实账号权限、厂商数据的业务含义或实际部署可用。限流故障测试在模拟厂商调用持续执行时真实终止 PostgreSQL 会话，确认新会话拒绝调用且保留 in-flight 状态；它不覆盖数据库整体恢复、跨主机网络分区或真实厂商断线。生产迁移、对象桶权限、账号级配额和应用生命周期仍须单独验证。

`TestPreviouslyArchivedQuote` 通过 `EMQUANT_ARCHIVE_REPLAY=1` 和显式测试 S3 配置只读回放已有归档，不向厂商请求新数据。2026-11-13 UTC 使用先前真实 SDK 联调留存的本地测试桶运行通过：对象哈希和解码可验证，旧行情按当前时间被判定过期；这不证明厂商真实性、字段含义、实时权限或延迟承诺。
