# Choice / EMQuant 接入手册

状态：开发中。已验证 Linux SDK 登录、历史序列、财务截面、交易日历、行情快照及独立 S3 归档；应用研究流程尚未接入真实厂商，不能据此声称已生成真实或实时研报。完成条件是必需数据集、来源血缘、快照、新鲜度、权限、故障处理及报告链路通过真实端到端验收。

## 运行依赖与凭证

- 项目采用 Go，Linux 原生绑定在 `backend/internal/dataservice/emquant`，通过 cgo 动态加载厂商库；不把 SDK 二进制、账号、密码、授权文件或登录日志提交仓库。账号密钥应由运行环境的 secret 机制传入，不放在命令行、日志、镜像或前端。
- 厂商库及同目录的服务器配置必须由部署方按授权独立提供，SDK 会写入运行目录，应使用可写的隔离副本。组件当前只提供库接口，生产配置、进程管理和应用注册尚未实现。
- 官方 Linux C++ SDK 的 `EmQuantAPI.h` 可从[厂商下载中心](https://quantapi.eastmoney.com/Download?from=web)获取。2026-11-13 下载的 x86-64 动态库与用户提供的 Python 包内同架构动态库 SHA-256 一致；这不保证未来版本 ABI 一致。
- 用户已确认允许数据持久化、向用户展示及第三方模型处理；应用仍须登记具体数据产品和字段权限，再启用对应生产用途。

## 已确认字段

| 数据 | 口径 | 状态 |
| --- | --- | --- |
| `VOLUME`、`AMOUNT`、`TURN` | 用户转述 Choice 终端：成交量为股、成交额为元、换手率是百分数；内部比例为百分数除以 100 | 已实现部分字段映射和原始归档，尚不是完整日线 |
| `IncomeStatement_9`、`IncomeStatement_61` | 用户转述：普通企业营业收入、归母净利润，金额单位元 | 已验证指定报告期 CSS 可取数并归档，公告和版本关联未实现 |
| `ReportDate`、`Type` | 用户转述：`ReportDate` 是报告期末；`Type=1/2/3/4` 为合并、母公司、合并调整、母公司调整 | 不得把报告期冒充公告时间 |
| CFN 资讯日期 | [官方 MATLAB 手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_Matlab.html)说明公告 `datetime` 是展示日期，部分盘后公告展示为下一交易日；`eitime` 对公告仅提供 2017-01-01 之后的日期 | 不能用展示日期或仅日期的生产时间推断盘中精确披露时点；不能据此证明财务版本 PIT |
| `tradedates` | 官方手册列出上交所和深交所市场参数及日频查询 | 已验证上交所历史样本；只映射返回的开市日期，不推断缺失日期为休市 |
| CSD/CSS 请求 | 官方手册说明单次最多 64 项指标、函数每分钟不超过 700 次 | 已限制指标数量；账号级、跨进程限流及退避未实现 |

厂商的[Python 手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_Python.html)和 [Linux C++ 手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_CPP_Linux.pdf)定义 API、参数和内存释放；字段口径以具体数据产品及版本为准。用户提供的终端口径应在正式数据产品登记中记录来源与确认人，不把上述概括当作完整合同原文。

## 未确认的信息及处理

| 项目 | 未确认内容 | 当前处理 |
| --- | --- | --- |
| 盘中行情 | `NOW` / `TIME` 的正式定义、时区、授权产品、是否实时及延迟承诺 | 仅保存厂商返回和实际观察时间；不能仅凭一次秒级样本宣称实时或 SLA |
| 复权和停牌 | `TAFACTOR` 归一化基准、停牌状态编码与停牌日 OHLC/量额返回 | 不生成缺少已验证口径的完整日线，不以零或前值填充 |
| 财报历史版本 | 公告日期、公告 `infoCode` 与财务修订值的准确关联，按历史时点重建能力 | 不把报告期或展示日代替披露时间；未证明 PIT 时不声称历史快照正确 |
| 产品覆盖与额度 | 报告正文、历史行业分类、指数、融资融券的具体权限、历史深度、并发及行情快照限频 | 按数据集逐项探测并登记；限流时返回错误并遵守账号统一限流，不虚构数据 |
| 原生 SDK | 多进程/多线程、断线与重连、停止失败及 ABI 跨版本保证 | 单进程串行并对回调错误失效；隔离、恢复、跨进程控制及版本兼容仍需验证 |

这些未知项应在对应报告的“数据与限制”中披露；能由已验证来源和规则生成的内容继续处理，无法满足必需章节或实时性要求时按照项目的 limited / 弃权规则处理，不用 fixture 或模型知识补值。数据集的实际事件时间、接收时间、系统可用时间与报告冻结截止不能混为一谈。

## 归档、验证与剩余工作

SDK 只暴露解码后的类型化结果；组件将该结果按内容哈希写入 S3 兼容存储，关联请求指纹和字段位置。它不是厂商原始网络字节。原始对象与数据库记录的关联、可见时间、快照冻结、权限撤销和旧写入保护尚需在数据服务与迁移中实现。不得丢弃 `MappedRecord` 的血缘后直接写入当前 `records` 表。

行情映射准备组件从归档校验单证券 `TIME,NOW` 请求、数据哈希、接收时间与字段位置，拒绝过期或不匹配的数据；单精度价格按其实际精度转成十进制字符串。映射参数必须提供时间和单位的依据引用、许可引用及新鲜度阈值；声明实时或延迟还需延迟依据引用。**引用字符串本身不是验证**：生产数据治理层必须解析并核验真实依据、权限和适用产品；在此之前不能将映射结果作为已验证实时行情或写入研究快照。当前厂商 `NOW/TIME` 及延迟口径仍未确认。

已按官方头文件新增 CFN 公告／资讯元数据调用与归档准备，模拟动态库覆盖模式、上游错误、归档失败和请求指纹；当前尚未用真实账户验证该接口的权限、响应形状或字段映射。厂商返回的 URL 和文本是不可信数据，不得执行其中的指令，也不得以返回的 URL 绕过已登记数据源进行任意抓取。元数据不等于公告正文。

开发验证：在 `backend` 执行 `go test -race ./internal/dataservice/emquant`；默认测试使用合成样本。`TestLiveSDK` 和 `TestLiveArchiveS3` 只在显式设置 `EMQUANT_INTEGRATION=1` 及相应环境后运行，使用真实账号会消耗厂商额度，后者会向指定 S3 桶写真实数据。`TestLiveCFN` 还要求 `EMQUANT_LIVE_CFN=1`；当前尚未运行。真实配置只由 secret 管理注入，不提交测试录制结果。

后续还需要实体和行业目录、公告正文及财报版本、完整日线与资金数据集、跨 worker 限流、报告各来源时间展示、生产环境配置以及真实数据加真实模型的端到端验收。工程计划与当前状态见 [接入交接](handoffs/2026-11-12-emquant-probe-codex.md)及 [ADR-0004 草案](https://github.com/clawhunt-cloxier/vera-main/pull/20)。
